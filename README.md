# MYSTETSVO — Цифровий хаб українського мистецтва 🇺🇦

[![GitHub Pages Deployment](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?logo=github)](https://dbyrba.github.io/mystetstvo/)
[![Netlify Status](https://img.shields.io/badge/Netlify-Deployed-00C7B7?logo=netlify)](https://mystetstvo-hub.netlify.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Вебплатформа для популяризації, дослідження та збереження шедеврів українського візуального мистецтва: від традиційного народного розпису та авангарду 1920-х років до сучасних цифрових медіа, генеративної графіки та відеоарту.

## 🏛️ Архітектура проєкту (5 сторінок)

1. `index.html` — **Головна сторінка:**
   - Hero-блок з ключовими показниками (1200+ робіт, 84 події, 600+ митців)
   - Каталог напрямків у форматі Bento-Grid
   - **Відеоманіфест «Мистецтво в русі»** з адаптивним HTML5-відеоплеєром (`art-video.mp4`)
   - Афіша найближчих подій з інтерактивними фільтрами
   - Інтерактивний паспорт твору «Гуцульська вербниця» з таймлайном провенансу
   - Форма співпраці з валідацією та модальним фідбеком

2. `gallery.html` — **Галерея цифрового та класичного мистецтва:**
   - Інтерактивні таби-фільтри (Всі, Генеративна графіка, 3D & Скульптура, Живопис, Відеоарт)
   - Вбудований прев'ю-плеєр відеоарту
   - Lightbox-модальне вікно для детального перегляду робіт

3. `artists.html` — **Реєстр митців та резидентів:**
   - Портрети, біографії та спеціалізації провідних українських митців
   - Картки з тегами медіа (генеративна графіка, 3D, AR, саунд-арт)

4. `events.html` — **Календар культурних подій:**
   - Інтерактивна афіша з фільтрацією за типами (лекції, майстер-класи, екскурсії)
   - Інтеграція «В календар» (Google Calendar / iCal)
   - Модальне вікно швидкої реєстрації (RSVP)

5. `about.html` — **Про арт-хаб:**
   - Маніфест місії та аналітичні показники
   - Принципи роботи (Зберігаємо, Відкриваємо, Поєднуємо)
   - Контактні реквізити, адреса у Львові та інтерактивна форма зв'язку

## 🛠️ Стек технологій

- **Семантична верстка:** HTML5 (W3C валідована розмітка, доступність ARIA)
- **Стилізація:** CSS3 (Custom Properties, Flexbox, Grid, Responsive breakpoints, backdrop-filter)
- **Інтерактивність:** Чистий Vanilla JavaScript (ES6+, модульна логіка без зовнішніх бібліотек)
- **Медіа:** Вбудований MP4-відеоарт HD 720p 60fps, оптимізовані зображення
- **Контроль версій:** Git, GitHub (гілкування `main` / `feature/*`, merge, commit logs)
- **CI/CD & Деплой:** GitHub Pages, Netlify Edge CDN

## 💻 Інструкція із запуску та розробки

### Клонування репозиторію
```bash
git clone https://github.com/dbyrba/mystetstvo.git
cd mystetstvo
```

### Локальний перегляд
Відкрийте будь-який HTML-файл у браузері або запустіть локальний сервер (наприклад, Live Server у VS Code):
```bash
# Через npx serve
npx serve .
# або відкрийте index.html
start index.html
```
